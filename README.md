# 💎 Diamond Price Prediction (Machine Learning)

## 📌 Project Overview
A machine learning project developed for the IT 461: Principles of Machine Learning course at King Saud University. This project builds a predictive regression model to estimate diamond prices based on physical attributes, including the "Four Cs" (Carat, Cut, Color, Clarity) and structural dimensions.

## 🛠️ Technologies Used
* **Language & Environment:** Python, Jupyter Notebook
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
* **Key Techniques:** Data Preprocessing, EDA, Regression Modeling

## 📂 Repository Structure
* `/Dataset`: Contains the original and preprocessed datasets.
* `Diamond_Price_Prediction.ipynb`: The main notebook covering the full pipeline from data analysis to model training.
* `Presentation.pptx`: The project presentation slides.
* `Report.pdf`: The complete academic project report detailing our methodology.

## 📊 Dataset
The dataset includes features such as:
* **Numerical Features:** Carat, Depth, Table, X (length), Y (width), Z (depth).
* **Categorical Features:** Cut, Color, Clarity.
* **Target Variable:** Price (in USD).

## 💡 Methodology & Key Results
1. **Data Preprocessing:** Encoded categorical variables and scaled numerical features for optimal model performance.
2. **Exploratory Data Analysis (EDA):** Analyzed feature distributions and correlations to identify the main price drivers (e.g., Carat and dimensions).
3. **Modeling:** Trained, tuned, and evaluated multiple regression algorithms to achieve high prediction accuracy.
